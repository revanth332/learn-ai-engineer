Core First-Principles Formulas & Architectural Invariants

Production mathematical formulas and algorithmic guarantees implemented in this repository.

Byte-Pair Encoding (BPE) Foundations

Base byte vocabulary $V_0 = \{0..255\}$. Iteratively greedily merges the highest frequency adjacent byte-pair into a new token ID $k = 256 + i$.

Full Jitter Exponential Backoff Resilience

Formula: $T_{wait} = \min(T_{max}, T_{base} \cdot 2^{attempt}) \times U(0, 1)$. Prevents clustered thundering herds on rate-limit recovery.

Okapi BM25 Sparse RSJ IDF Information Retrieval

Formula: $\text{IDF}(q_i) = \ln\left(1 + \frac{N - n(q_i) + 0.5}{n(q_i) + 0.5}\right)$. Floor-smoothed to 0 to prevent negative scoring on ultra-frequent terms.

Reciprocal Rank Fusion (RRF) Hybrid Retrieval

Formula: $\text{RRF}(d) = \sum_{m \in M} \frac{1}{k + r_m(d)}$, with constant $k=60$. Invariant to arbitrary score scales between dense cosine and BM25.

Cross-Encoder Re-Ranking Re-ranking

Combined score: $S = 0.50 \times \text{Coverage} + 0.30 \times \text{NGramBigram} + 0.20 \times \text{ProximitySpan}$. Eliminates dense false-positives.

The RAG Triad (Upcoming) Evaluation

Evaluates 3 axes: 1. Context Relevance (query vs retrieved text), 2. Groundedness (answer vs context), 3. Answer Relevance (answer vs query).

ReAct Cycle Detection (Upcoming) Agent Loop

Explicit state transition machine: $[\text{Thought} \to \text{Action} \to \text{Observation}]^* \to \text{FinalAnswer}$. Traps repeated action hashes to halt cycles.

LoRA Rank Decomposition (Upcoming) Fine-Tuning

Weight update $W = W_0 + \Delta W = W_0 + \frac{\alpha}{r} (B \cdot A)$, where $A \in \mathbb{R}^{r \times d_{in}}$ and $B \in \mathbb{R}^{d_{out} \times r}$ with $r \ll d$.
